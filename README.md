## Project Description
This project demonstrates a simple HTML webpage created as part of a pair programming collaboration exercise. The page introduces team members and their respective roles using basic HTML structure and semantic elements. The goal of the project was to practice collaborative development workflows using Git and GitHub while building a simple web page.

## Technologies Used
- HTML5
- Git
- GitHub
- Visual Studio Code

## Features
- Displays a list of team members
- Shows each member's role
- Simple and clean HTML structure
- Beginner-friendly project for practicing collaboration
- Version control using Git and GitHub

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/jacobricktified/iyf-s11-week-03-pair-jacobricktified.git
```

2. Navigate into the project folder.

```bash
cd your-repository
```

3. Open `index.html` in your preferred web browser.

Alternatively, if using Visual Studio Code:

- Install the **Live Server** extension.
- Right-click `index.html`.
- Select **Open with Live Server**.

## Lessons Learned
During this project, I learned:

- How to collaborate with another developer using GitHub.
- How to create and switch between Git branches.
- How to commit meaningful changes.
- How to resolve merge conflicts.
- The importance of writing clean and readable HTML.
- Basic GitHub collaboration workflow using Pull Requests.

## Challenges Faced
Some of the challenges encountered included:

- Managing changes made by multiple contributors.
- Understanding Git branching and merging.
- Avoiding duplicate HTML elements during collaboration.
- Ensuring the project remained organized after merging code.

These challenges were solved by communicating with teammates, reviewing Pull Requests carefully, and following proper Git workflows
